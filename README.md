# 📊 Sistema de Cálculo de Médias em C

> Projeto desenvolvido como parte dos estudos de **Engenharia de Software**, focado em demonstrar lógica de programação, estruturas de repetição (`do-while`), condicionais (`if-else`) e manipulação de variáveis em linguagem C.

---

### ⚙️ Funcionalidades
- **Menu Interativo:** O usuário pode realizar quantas consultas desejar sem precisar reiniciar o programa.
- **Cálculo de Média Aritmética:** Processamento de três notas inseridas via terminal.
- **Avaliação de Status Automática:** Classifica o aluno com base na média obtida (Aprovado, Recuperação ou Reprovado).

---

### 🚀 Como Executar
1. Certifique-se de ter um compilador C instalado (como GCC) ou utilize um ambiente online (ex: [GDB Online](https://www.onlinegdb.com/online_c_compiler)).
2. Copie o código do arquivo `main.c` deste repositório.
3. Cole no seu compilador, compile e execute.

---

### 🛠️ Tecnologias Utilizadas
- **Linguagem C**
- **Conceitos:** Loops (`do-while`), Condicionais (`switch-case`, `if-else`), Entrada/Saída de dados (`scanf`/`printf`).
